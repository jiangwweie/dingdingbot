本稿优先于此前有关新增Regime、全策略统一A1、整票立即保本和所有阶段保留原时限的建议。那些稿件保留讨论溯源，不是当前待实施清单。

## 2. Owner已确认的业务边界

| 事项 | 已确认边界 |
|---|---|
| 目标 | 有限风险捕捉趋势右尾，不要求每笔保本或持续交易 |
| 人工参与 | 系统独立运行；Owner偶尔收紧保护、减仓或暂停 |
| 盈利仓 | 结构退出为主，接受较大浮盈回吐 |

## 3. 建议机制

### 3.1 SOR：突破验证阶段

使用真实完整入场均价、数量、初始Stop与冻结策略参考。取消固定TP减仓，不强制将Stop移到入场价附近。

保留原SOR突破收回、会话及趋势确认前时间退出。失败条件优先于趋势阶段转换：同一轮同时满足失败退出和趋势确认时先退出。初始Stop始终有效，不因等待确认而撤销或放宽。

**初始技术候选**：一小时闭合收盘沿有利方向达到实际入场到初始Stop距离的1.2倍，且能够形成比已确认Stop更严格的合法小时结构Stop，正式安装并确认后进入趋势阶段。

“达到1.2R”是趋势管理里程碑，不是成交或已实现收益。没有真实TP时不生成假的TP完成事件。

### 3.2 SOR：趋势持有阶段

保持主要/全部实际余仓；不固定减半，不强制保本。小时闭合结构推动Stop，仅收紧。

初始候选沿已回放机制：最近4根完整1h结构＋0.5×ATR14（TR算术平均），最小改善2tick。多头使用区间低点减缓冲，空头高点加缓冲；叠加初始Stop、已确认Stop、Owner更严格约束，取最严格合法保护。

**不再因原入场会话结束或原等待期限单独退出趋势仓。** 原期限约束的是尚未发展起来的突破，不应继续机械截断已确认趋势。交易所Stop实时有效；小时更新不是延迟执行触价止损。

代价：可能持仓更久、支付更多资金费、回吐更多浮盈并占用后续机会额度。结构失效、已存在的安全退出和Owner明确退出仍有效；不顺带添加任意新资金费/最大持仓小时平仓阈值。具体异常/成本处理在实施前规格中明确，不能默默无限忽略。

### 3.3 局部重复试错限制

它是**尝试记账与准入限制**，不是新的通用趋势信号。建立同币同方向的局部结构身份，记录原策略产生的独立尝试。

- 两次失败暂停新入场，不停止已有保护和退出。
- 原信号false→true、换策略名、服务重启、时间流逝不能自动清零。
- 新结构确认后恢复自身门禁；仍须原策略产生新的合法Signal/Episode，不重放被拒旧信号。
- 不跨币种自动扩展暂停，不增加全局日亏规则。
- 跨策略只有能证明共享同一市场结构才共享消耗，不能仅凭币种同向就不加区分地相互阻断。

**这一部分尚未冻结可执行算法。** 旧稿20根区间、6根收敛、1ATR脱离和ER条件只保留为备选，不能自动带进V0。最终定义必须回答结构身份、失败归因、跨策略关联及恢复门槛，并用震荡/突破路径检验。技术选择由工程方负责，不要求Owner猜指标数值。

### 3.4 其他策略与人工续管

BRF2、CPM、MI、MPG保留自身现有退出，不复制SOR变更。局部试错通用能力可复用，但结构关联必须尊重策略语义。

人工减仓、收紧保护后继续AUTO是独立执行能力，不依赖采用新SOR退出。人工TP普通限价，单一计划；与原自动TP的替换、满额真实成交后续管、取消不恢复旧TP等已确认规则见[手机设计](2026-11-16-mobile-owner-control-detailed-design.md)。现有生产App外部干预语义不因本稿自动改变。

## 4. 负面影响与设计责任

| 负面影响 | 机制原因 | 处理边界 |
|---|---|---|
| 小赚变亏、胜率可能下降 | 无固定TP/强制BE，等待趋势 | 原失败退出与试错期限保留，不能保证消除首次假突破 |
| 大赢家显著回吐 | 小时结构给反弹空间 | Owner可收紧/减仓；不默认再加固定回吐阈值 |
| 暂停错过结束震荡的突破 | 两次失败后拒绝新尝试 | 恢复必须观察新结构，不靠定时器也不轻易清零 |
| 跨策略误伤 | 共用局部结构定义不当 | 结构关联可解释，不能仅币种同向无限共享 |
| 资金费、容量排挤 | 趋势持有时间变长 | 核算真实成本与占用，组合顺序验证，不用单票求和代替账户收益 |
| 定义/参数过拟合 | 围绕最近输赢添加条件 | 参数少且有明确职责，邻近值敏感性、独立行情核验，不为保住个别赢家回改 |

架构可落地不等于参数已最优。工程方负责规则无歧义、执行正确与代价核验；Owner负责既定风险偏好与超范围变更，不承担ATR等技术选择。

## 5. 已有证据与缺口

[A1回放报告][replay]在固定18笔入场下展示完整Runner的机会与代价，且BRF2未随SOR改善。它没有包含完整局部试错，也不是资金重算后全部Signal的账户回测。

此前[Regime定义核验][regime]只映射14笔原入场状态，不能作为本稿新增准入收益证据；该新增Regime不纳入当前方案。市场原始窗口后修订/实际HTTP时点、部分成交、资金费与执行延迟等边界仍需保持。

**不能将A1约500U的票级模型结果称为当前完整方案的预期收益，也不能用手机原型证明后台已具备安全续管。**
