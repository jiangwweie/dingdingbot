# 手机操作帮助：独立交互原型

**仅本地模拟，不连接生产API、不读取设备凭据、不发送交易、未发布。**

## 查看

在本目录启动静态服务，打开`index.html`。桌面同时显示说明与手机预览；窄屏只显示手机。

## 可点击流程

1. 持仓页右上角「操作帮助」→六种意图→单项影响与可展开示例。
2. 「进入操作」只打开模拟表单；填写→核实并预览→查看本笔变化→确认提交（模拟）→处理中→结果。
3. 普通操作表单也提供「这项操作会改变什么」，按需回到同一解释。
4. 桌面左侧或手机顶栏「交互原型」可切换TP1前、Runner中、人工止盈中；刷新或重置恢复模拟状态。

## 产品边界

- 日常持仓页保留直接按钮，不自动弹教学，不按盈亏或行情推荐交易。
- 减仓不立即保本；保留原目标价条件。Runner中减仓继续原追踪。
- 独立人工止盈与减仓冲突时，先处理人工计划。
- 人工止盈完整目标成交后，余仓按原阶段继续；挂出不等于成交。
- 单笔全平不暂停新开仓；暂停新开仓不平已有仓。
- 所有价格、数量、结果均为虚拟示例，不能作为实盘证据。

语义参考：[当前人工协作合同](../../superpowers/specs/2026-11-16-owner-cooperative-execution-v1.md)。本原型不改变合同或生产规则。
