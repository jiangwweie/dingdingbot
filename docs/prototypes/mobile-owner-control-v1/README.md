# 手机操作端V1静态原型

入口：[index.html](index.html)。设计依据：[手机操作端设计](../../superpowers/specs/2026-11-16-mobile-owner-control-v1-design.md)。

**本地模拟，不连接交易所、生产API、设备认证或推送。** 所有持仓与结果都是演示数据，刷新重置。不是可安装上线的PWA或交易实现。

## 查看

直接打开HTML，或在工程根目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory docs/prototypes/mobile-owner-control-v1
```

浏览器打开 `http://127.0.0.1:8766`。该地址仅在运行服务器的电脑可用，不是手机远程访问地址。

## 体验

- 持仓：减仓、全平、止盈/止损；提交前预览，提交后可以关闭面板。
- 委托：保护只可调整，人工TP只保留一个、可替换/取消。
- 主控：全局与策略新开仓开关，保留Owner单独暂停。
- 顶部“模拟原型”：切换成功、明确拒绝、结果待核实、断网、重置；待核实场景可手动模拟核实完成。
- 顶部铃铛：设备/通知目标的只读设计预览；不是实际绑定功能。

本原型为清晰演示一次操作的全过程，一次只接受一个模拟写请求；生产设计仍按每票协调，其他票的正常自动运行不受此原型限制。人工TP数量超过减仓后余量时先阻止并要求修改计划，不静默改变指令。模拟费用、精度、百分比取整不是交易所验收。

## 设计准则

产品意图通过交互、按钮、功能与信息流呈现，不堆砌解释文字。确认内容、输入错误与执行异常保持具体简短。桌面侧栏是原型评审工具，手机不显示。

## 本轮验证

Playwright浏览器检查：减仓余量回写；阻止放松空仓Stop；收紧Stop回写；全局暂停保留单策略选择；未知结果锁定且不假报成功；人工TP创建/替换/取消；取消TP保留Stop；减仓与TP数量冲突；明确拒绝保留仓位；关闭面板后全平完成且不强制弹回；断网阻止写操作。手机390×844截图已人工检查。
